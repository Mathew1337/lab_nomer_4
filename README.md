# lab_nomer_4
# Сокращатель ссылок (URL Shortener)

## Описание проекта

Данный проект представляет собой упрощённый сервис сокращения ссылок.

Система позволяет:

* сохранять длинные ссылки;
* автоматически генерировать короткие коды;
* получать длинную ссылку по короткому коду;
* проверять существование кода;
* удалять ссылки;
* подсчитывать количество переходов;
* определять самую популярную ссылку;
* выполнять поиск по ключевому слову;
* изменять существующие ссылки;
* выполнять обратный поиск по длинной ссылке.

---

## Используемые структуры данных

В проекте используются словари Python (`dict`), реализованные на основе хеш-таблиц.

### url_map

Хранит соответствие:

Короткий код → Длинная ссылка

Пример:

u7vp8r → https://google.com

### reverse_map

Хранит соответствие:

Длинная ссылка → Короткий код

Используется для обратного поиска и предотвращения дублирования ссылок.

### click_count

Хранит количество переходов по каждой короткой ссылке.

Пример:

u7vp8r → 3

## Реализованные функции

### Обязательная часть

* Добавление новой ссылки (`add_url`)
* Получение длинной ссылки по короткому коду (`get_url`)
* Проверка существования кода (`exists`)
* Вывод всех сохранённых ссылок (`get_all_links`)

### Дополнительная часть

* Запрет создания одинаковых коротких кодов
* Возврат существующего кода для одинаковой ссылки
* Удаление ссылки по короткому коду
* Подсчёт переходов по ссылке
* Определение самой популярной ссылки
* Поиск ссылок по слову
* Сортировка по короткому коду
* Ограничение длины короткого кода
* Изменение длинной ссылки
* Обратный поиск короткого кода по длинной ссылке

---

## Сложность основных операций

| Операция               | Сложность  |
| ---------------------- | ---------- |
| Добавление ссылки      | O(1)       |
| Получение ссылки       | O(1)       |
| Проверка существования | O(1)       |
| Удаление ссылки        | O(1)       |
| Обратный поиск         | O(1)       |
| Поиск по слову         | O(n)       |
| Сортировка             | O(n log n) |
